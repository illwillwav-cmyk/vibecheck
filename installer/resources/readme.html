What gets installed

  • /Applications/VibeCheck.app, the application.
  • Optional: a vibecheck command in /usr/local/bin, for scripts and CI. Choose Customize to add it.

Plugin scanning

Scanning loads third-party code that is allowed to crash, so VibeCheck probes each plugin in a separate process and carries on if one fails. Plugins that crash a scan are listed under Skipped in the Plugin Manager.

What AI Check can and cannot tell you

It reads metadata, symbol names and strings in a plugin's file. That is informative for unwrapped, unstripped plugins and says nothing about encrypted or copy-protected ones, which it marks as unreadable instead of guessing. The score measures template and boilerplate habits, not authorship.

Where it keeps settings

The plugin list and your theme choice live in ~/Library/Application Support/VibeCheck. Removing that folder resets the app.

Uninstalling

Drag the app to the Trash, or run Uninstall VibeCheck.command from the disk image to also remove the command line tool and the installer receipt.

Licences
