What it does

  • Graph Analyzer — frequency response, distortion, phase, aliasing and more, measured by playing test signals through the plugin.
  • Plugin Health — thirteen robustness checks: finite output, buffer-size independence, latency honesty, state save and restore.
  • AI Check — reads each plugin's file for the marks of generated code, and with a Deep check measures what its audio thread does.
  • A/B Compare and Performance Profiler — two plugins side by side, and what each one costs the CPU.

Opening it the first time

These downloads are not signed with a paid certificate, so your computer asks once before it runs them. Nothing is wrong with the file.

Windows: "Windows protected your PC"
  1. Run the installer you downloaded.
  2. Click More info.
  3. Click Run anyway.
Mac: "can't be opened because Apple cannot check it"
  1. Open the disk image and drag VibeCheck into Applications.
  2. Right-click (or Control-click) VibeCheck and choose Open, then Open again.
  3. If that option is missing: System Settings → Privacy & Security, scroll down, click Open Anyway.
